About & How I Work

A bit about my background, learning approach, and what I enjoy building.

Vibe-Coding with AI

I don't claim to know every language under the sun. Instead, I focus on having a clear architectural vision, strong UX taste, and using AI coding assistants to bring complex ideas like Wayland desktop widgets and automation tools to life quickly.

Full-Stack Python

My primary development foundation is Python and Django. I enjoy building end-to-end applications from the ground up—designing database schemas, implementing authentication flows, and building clean, responsive interfaces.

Linux & Clean Desktops

I daily-drive Linux with Wayland compositors. I care deeply about how software feels in daily use: minimal memory consumption, zero unnecessary background bloat, and smooth physical spring animations rather than rigid jumpy transitions.
