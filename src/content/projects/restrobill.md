## Building a Real-World Billing Flow

RestroBill was developed to tackle the day-to-day workflow of managing orders and printing bills in a small restaurant setting. 

Instead of dealing with overly generic dashboard templates, this project helped me dive deep into:
- Modeling relational databases for menu categories, items, tables, and invoice items.
- Handling transactional integrity during order checkouts.
- Designing an intuitive billing flow so staff can quickly add items to an active table without getting stuck in multi-page reloads.
