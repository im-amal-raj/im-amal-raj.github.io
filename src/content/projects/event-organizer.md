## Community Event Management

Managing participants, schedules, and permissions can quickly become messy. I built this application to provide a simple, centralized portal for local event organizing.

- Implemented role-based permissions separating event organizers from general attendees.
- Designed clean form validations and feedback states.
- Documented the architecture and database schema in an in-depth Dev.to case study.
