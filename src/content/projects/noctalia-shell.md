## An Anti-Bloat Engineering Operating Environment

Noctalia is a custom-engineered daily driver Linux environment tailored for maximum focus, sub-millisecond audio feedback, and distraction-free software development.

### Systems Philosophy

- **Zero Unnecessary Background Daemons**: Everything running on the machine must justify its CPU cycles and wakeups.
- **Broadcast Vocal Pipeline**: Audio calibrated for YouTube recording directly inside PipeWire with real-time DeepFilterNet neural noise reduction.
- **Native Keyboard Navigation**: High-frequency workflows mapped to tactile keyboard chords with `rust-island` launcher integration.
